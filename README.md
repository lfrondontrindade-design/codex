# Nossos trabalhos

Repositório para organizar e guardar os projetos, documentos e outros trabalhos desenvolvidos com o apoio do Codex.

## Organização

Cada trabalho terá uma pasta própria, com um nome descritivo e instruções de uso quando necessário. Os arquivos serão adicionados conforme os trabalhos forem criados.

Não salve senhas, chaves de acesso, arquivos `.env` ou dados pessoais sensíveis neste repositório.

## Ambiente de desenvolvimento

Este repositório ainda não contém aplicações ou dependências. A instalação e os testes serão definidos conforme cada projeto for adicionado.

## Como salvar novos trabalhos

Ao trabalhar com o Codex, indique este repositório e peça para salvar os arquivos nele. Conversas e trabalhos de outras sessões não são sincronizados automaticamente.
